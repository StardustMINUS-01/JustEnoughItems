# JEIunofficial

An unofficial fork of [JustEnoughItems (JEI)](https://github.com/mezz/JustEnoughItems)
for Stellar Remnants.
Enhances JEI with several features.

## Notice

This is an unofficial fork and is not affiliated with mezz or the GTNH Team.
The mod ID remains `jei` for dependency compatibility:
**do not install this mod alongside the official JEI**.
If you run into unexpected behavior or crashes, please first check whether
the issue also occurs with the official JEI. Only contact mezz if the issue
is clearly present in the official JEI.
